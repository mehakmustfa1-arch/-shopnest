# ShopNest - Online Shopping App

AUREX Full-Stack Engineering Internship - Month 3 Project

## About
ShopNest ek complete E-commerce website hai jahan Customer products browse karke order kar sakta hai aur Admin products aur orders manage kar sakta hai.

## Tech Stack
- Frontend: React, React Router, Axios, Tailwind CSS
- Backend: Node.js, Express.js, Mongoose
- Database: MongoDB Atlas
- Auth: JWT, bcrypt

## Features
- Login / Register
- Product Listing, Search, Filter
- Cart + Checkout + Order Tracking
- Admin Dashboard + Product CRUD + Order Management
